# Step1
最初に以下のような解き方を考えたが、コードに落とし込むことができなかった。

**解き方**
1. 与えられたリストの要素を先頭から順に見ていく。
2. 見ている要素を、文字ごとにバラバラにして「その要素の袋」を作る。
    - 例： "eat" -> e, a, t
3. 既に作った袋の中に、今見ている要素の袋と「中身が同じ袋」があるかチェックする。
    - e, a, t と t, e, a は、順番は違うが中身は同じ。
    - どちらも a, e, t が1つずつ入っている。
4. もし同じ中身の袋がまだなければ、今見ている要素の袋を新しく作成し、その袋に対応するリストを作って、見ている要素を入れる。
    - 例： "eat" を見た場合、 e, a, t の袋を作り、対応するリストを ["eat"] にする。
5. もし同じ中身の袋が既にあれば、その袋に対応するリストに、今見ている要素を入れる。
    - 例： "tea" は "eat" と同じ中身の袋なので、 "tea" を ["eat"] に追加して、 ["eat", "tea"] にする。
6. 上記手順を、すべての要素について繰り返す。
7. 最後に、それぞれの袋に対応するリストをまとめて、2次元のリストとして返す。

**自身の課題と解決策**
- defaultdict の使い方を分かっていなかったため、 Arai60 の問題演習を通してよく使うライブラリの使い方を学習する。
- 時間計算量と空間計算量の見積りができていない。
    - 時間計算量・空間計算量について、プログラム全体として、どの処理が支配的であるかを見るようにする。
    - 計算量を聞かれたら、通常は最悪ケースで見積もるようにする。
    - 組み込み関数（list や dict）における時間計算量を理解して覚えておく。

**計算量**
- 時間計算量は O(NK log K), N は文字列の個数、 K は各文字列の最大長
- 空間計算量は O(NK), すべての文字列が別々のグループに属す場合、 key の数は N 個であり、各 key の長さは最大 K
